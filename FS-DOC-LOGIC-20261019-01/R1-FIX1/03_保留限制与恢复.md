# 保留限制与恢复

只使用原固定 Qwen 文本接口、工程内 Skill、原飞书入口和官方 CLI；模型、端口、并发、1024 token 输出配置、120 秒执行上限、两人白名单、零测试群、24 小时绝对期限及 Meegle 绑定配置均不改变。

本轮支持范围仍为文字和 UTF-8 TXT／Markdown／HTML，单文件 512 KiB、总解析文字 12,000 字符。全文逐段改写、Word／PDF／OCR、SFT、个人记忆、扩大项目和新增审批角色均未实施。

问题身份由对象、原记录和具体缺口组成；补答状态有逐字引用并经过 Qwen 语义复核。确定性检查只覆盖能够明确配对的局部记录及已知量纲矛盾，不宣称穷尽自然语言中的所有工程条件。语义判断仍可能失败，失败时保留输入并不交付未通过校核的候选稿。真实样例不能证明所有未来文章都不会出现语义错误，专业审核职责不变。

挂载适配器未修改；原 Meegle 接口仍不保证跨客户端原子版本更新。本轮不作生产推广或扩大运行范围的结论。

使用原入口 `/doc logic test 内容` 或 `/doc logic 8d 内容`。直接回复补充；`/doc 阶段稿` 保留未知并停止追问，`/doc 暂停`、`/doc 继续`、`/doc 放弃` 沿用原语义。只有原采用与挂载动作才可能产生业务写入，本轮实测不触发这些动作。

部署前确认无排队、运行、未知请求和待发送消息，备份受影响文件后重启原消费者；部署只写入受影响源码；重启后核对原模型、并发、白名单和零测试群，Meegle 适配器未变。回退时需先确认空闲，停止原消费者，恢复本轮部署备份，再启动同一个服务。不得另起第二个消费者，也不得终止共享 Ollama 服务。

原 r1.1 按短 key 批量登记的答案不作为“已解决”证据；原来源保留，下一次生成依据来源重新核对。没有导入个人规则、记忆或其他会话。
