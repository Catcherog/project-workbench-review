# 使用与回退

沿用原机器人试用会话与两人名单。本人具备本轮测试项目挂载入口；第二位测试者保留原范围的整理能力。

- /doc logic 8d：开始8D／异常分析，可在命令后附文字。
- /doc logic test：开始测试报告。
- 随后发文字或UTF-8 TXT、Markdown、HTML文件；直接回复归入当前稿。
- /doc 阶段稿、/doc 暂停、/doc 继续、/doc 采用、/doc 放弃。
- /doc target 测试报告：选择服务端绑定的测试交付物。
- /doc 挂载：采用当前内容后执行，返回实际对象链接。
- /doc 对账：查询结果未明的既有写入，不盲目重传。
- /doc sample、/progress sample保留；/chat返回普通聊天。

本轮验证后已结束该合成草稿并回到普通聊天，已挂载文件保留。再次整理使用开始命令。生成文件的业务状态是当时快照，挂载后状态以平台回执为准。材料、目标和有效意图均不变时不重复确认，实质变化仅处理相应部分。

文件最多512 KiB，总解析文字最多12000字符；输出上限1024token，生成总时限120秒。超限/不支持时说明读取边界，HTML图像、嵌入对象与外链不自动读取。零测试群；消息和附件返原提问者，不自动外发给联系人。

配置增量为document_logic.enabled=true、私有document-business.json及固定版本Meegle CLI。旧features.synthetic_data_only仍约束sample适配器。原模型、身份范围与唯一消费者保留。

官方工具：[飞书CLI](https://github.com/larksuite/cli) 1.0.98、[Meegle CLI](https://github.com/larksuite/meegle-cli) 1.0.27。本机已有lark-cli、meegle命令与专用profile fs-doc-logic-r1；运行Meegle置原服务bin并校验摘要。飞书CLI用于本人验收及读回，机器人继续原API/长连接。无独立MCP服务，Meegle官方CLI自身复用厂商MCP授权和后端。

回退前等当前任务结束并停止原消费者，按本机私有部署清单逐文件恢复，关闭document_logic.enabled，再启动同一服务。只停用挂载可撤去私有业务配置后重启。保留原工作树和共享Ollama；不删除已挂载文件。新表仍按原绝对24小时期限清理。

公开包在原Python依赖环境执行scripts/run_offline.sh可复跑89项，不访问飞书或模型。scripts/validate_content.py明确调用真实本地Qwen，依赖原私有配置，只使用合成材料且不向飞书发送；它不属于离线检查。
