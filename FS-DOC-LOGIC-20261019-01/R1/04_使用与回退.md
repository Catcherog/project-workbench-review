# 使用与回退

沿用原机器人本人试用会话及原两人名单。入口：

- /doc logic 8d：开始异常分析，可在同一条命令后附文字。
- /doc logic test：开始测试报告。
- 接着发送文字或 UTF-8 TXT、Markdown、HTML 文件；直接回复归入当前稿。
- /doc 阶段稿、/doc 暂停、/doc 继续、/doc 采用、/doc 放弃。
- /doc target 精确目标ID、/doc 挂载、/doc 对账：需要已装配且获准的业务连接；本次生产装配尚无此连接。
- /doc sample、/progress sample 保留原合成测试；/chat 返回普通聊天。

文件最多512 KiB，解析文字总量最多12000字符；模型仍使用原1024输出token和总120秒执行时限。超限或格式不支持会说明具体读取范围，不截断后声称全文检查。HTML图像及外链不自动读取。群配置仍关闭；私聊详细结果和附件只返原提问者。没有自动联系人外发。

本轮配置增量仅为 document_logic.enabled=true；旧 features.synthetic_data_only 继续约束原 sample 适配器，新增逻辑整理只接收两人名单内主动提交的本次资料。没有模型更换、下载、新权限或第二消费者。

回退先等待当前任务结束并停止原消费者，按本机私有部署清单恢复逐文件备份，将 document_logic.enabled 关闭，再启动同一个服务。新表保存短期任务数据，按原绝对24小时清理，不删除业务平台文件。不得替换整个工程、重置用户工作树或停止共享 Ollama。

公开包可在原Python依赖环境运行 scripts/run_offline.sh。此命令不连接飞书或模型。scripts/validate_content.py 是明确的真实本地 Qwen 合成验证入口，依赖原私有服务配置；没有配置时不要虚构身份启动。
