# 发现过的问题与修正范围

真实 Qwen 初次输出虽通过模型自检，仍出现遗漏反向指标、将处理后区间记录误作判据、量纲错误漏报、同一事件版本被误称独立事件，以及引用关系枚举不合约定。没有把初次自检当成验收通过，也没有把失败材料上传成真实业务事实。

修正包括：按原文标点保留句段位置；明确独立事件与版本关系；单位量纲和显式均值/区间记录作确定性检查；对原文明确同一事件的矛盾建议限制相应句子；引用仅在同一段内恢复可唯一定位的空白格式；结构/引用错误允许一次受总时限约束的 Qwen 修正，再执行语义检查。保留原值，程序注释与模型意见可区分。语义检查要结合命题的支持/反对/不足/冲突关系，不能把待检验命题误当作已认可事实。

这些定向样例只证明本轮已观察行为，不证明长期错误率为零。技术前提、因果充分性与专业采用继续由原专业角色负责；没有新增 PM 内容审批。未运行 SFT。
