## P01—P12

| 步骤 | 实现与定向证据 |
|---|---|
| P01 接收 | 原入口持久收件与身份/部门门禁；回执先于文件处理，生成异步单路。真实修正后3次反馈2.75—3.19秒；未承诺严格3秒上限。 |
| P02 定位 | 会话、文种与精确目标；同名不自动替换。本人唯一测试目标真实I02；未选目标可先整理。 |
| P03 读取 | TXT/MD/HTML原文指纹、行字符位置、完整/部分/失败状态；I01真正上传HTML并完整读取。视觉/外链明确未读。 |
| P04 提取 | Qwen分类信息身份，原始句段与模型意见分开；未知形成时间保留null；C01—C06。 |
| P05 对应 | 命题、来源段号、原句、支持/反对/不足/冲突及理由；引用、数字检查；C01—C07。 |
| P06 回查 | 复用同稿材料及答案，授权后在绑定目标读取关联附件；不可读保留限制。Meegle身份与节点过滤测试通过；实际节点/交付物读取通过。 |
| P07 补充 | 必要问题归同稿，已回答不重问；阶段稿、暂停/继续/放弃。I01真实补答保留2来源1答案；其他状态分支隔离验证。 |
| P08 生成 | 两类文种沿原Markdown交付，五项结构、修改、来源、缺口；真实Qwen C样例及I01平台附件读回。 |
| P09 检查 | 程序字段/引用/数值/量纲/统计检查与Qwen语义检查独立；有限结构修正；保留初次漏报记录。 |
| P10 采用 | 采用绑定内容指纹；内容变化失效，同目标不重复确认；采用不等于批准。I03隔离、I02真实采用均通过。 |
| P11 挂载 | Meegle精确项目/节点/交付物/实际指纹；守卫、幂等、读回。I02真实成功且重复无第二附件；跨客户端原子比较更新不受当前API保证。 |
| P12 接续 | 失败保留来源，未知只对账；取消和晚到结果拒绝。故障注入通过；实际I05提交后取消保留平台历史。 |

## I01—I06证据口径

| 场景 | 真实正常链 | 隔离故障或竞态 |
|---|---|---|
| I01 | 原本人会话命令、HTML、补充、两次Qwen、六对象读回通过 | 同稿、原绝对期限、回执先于下载及持续鉴权通过 |
| I02 | 正确测试项目节点交付物挂载、字节读回、重复仍1附件通过 | 同名不同身份、目标修订变化、原生节点归属、未确认空字段拒写通过 |
| I03 | 真实采用/挂载后平台仍未审核、节点未开始 | 修改使旧采用失效，旧审核不迁移、已审核目标拒写通过 |
| I04 | 未故意破坏真实服务 | 读取/模型失败、远端成功应答丢失、只对账不重写通过 |
| I05 | 真实提交后取消，附件与历史保留，返回普通聊天 | 排队/分发守卫撤销、旧结果拒绝、发文件期间撤销通过 |
| I06 | 真实运行仅绑定本人1目标；保留原两人整理白名单 | 两用户/项目越权、附件指令、跨任务污染、个人记忆调用0通过 |

C01—C06由真实固定Qwen生成并经Codex定向核对，C07为额外正向案例。最终确定性重放有单独记录，不冒充新增模型推理。故障分支不声称真实业务故障演练；专业批准、节点完成、发布、GPT审计、用户验收不受模型文字控制。
