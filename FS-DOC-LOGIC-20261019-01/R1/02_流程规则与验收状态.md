# 流程、规则与验收对应

需求 v1.0-exec；隔离受测实现 425517988bee847a133b333dc611705a67618683。所有 I 场景中的业务平台替身均明确属于合成验证。

## P01—P12

| 步骤 | 实现和观察 | 当前边界 |
|---|---|---|
| P01 接收 | 原 EmbeddedPoC/Gateway 持久收件、原白名单/群@门禁；生成移到受控单路执行，接收线程仍可处理补充 | 模拟响应检查通过，当前真实UI未验收 |
| P02 定位 | 会话范围固定，文种选择；目标以精确ID解析，同名不自动映射 | 业务目标连接未装配；不影响先整理 |
| P03 读取 | TXT/Markdown/HTML，原文指纹与行/字符位置；完整/部分/失败状态，大小及编码限制 | 图片/OCR/外链不读取；真实上传待I01 |
| P04 提取 | Qwen分清信息身份；原始句段与模型意见分开；未知形成时间保留null | 技术解释不变成实测或批准 |
| P05 对应 | 每条重要命题带来源段号、原句、关系和推断理由；程序校对引用 | 语义判断仍须专业审核 |
| P06 回查 | 同稿材料与答案复用；业务连接接口要求先核用户/项目后取数 | 真实项目回查受I02连接缺失阻挡 |
| P07 补充 | 回答进入同一稿；已回答问题过滤；阶段稿、暂停、继续、放弃；无后台自动催办 | 对已知均值/单位矛盾作定向问题修正；新入口待I01 |
| P08 生成 | 两类文种使用原Markdown交付方式，五项基础结构、差异、来源、缺口 | 不另建编辑器或平行表单 |
| P09 检查 | 引用/数值/单位/版本程序检查与Qwen语义检查分开；有限结构修正 | 自检不等于专业批准；保留历史漏报事实 |
| P10 采用 | 采用绑定内容指纹；改内容后不能沿用；同目标未变化保留有效意图 | 无PM新增审批；真实业务状态未读取时明示未知 |
| P11 挂载 | 精确项目/节点/交付物/修订端口，幂等账本，提交前守卫和读回校验 | 仅替身验证，生产装配明确不可用 |
| P12 接续 | 读取/模型失败保留来源；未知写入只对账；取消与晚到结果拒绝；不删历史 | I04—I06隔离注入通过；实际平台随I02补验 |

## C 与 I 的状态口径

C01—C06：真实固定 Qwen 合成整理及 Codex 定向核对通过；逐例输入、输出、实际模型、原生成代码摘要、最终确定性重放代码及语义检查均在 evidence/content/。C07 是额外充分证据肯定样例。

I01—I06：所需隔离分支已执行，见 test_doc_logic.py。I01真实本人文字/附件/回答链未执行；I02正常真实平台挂载未执行。两者不因合成分支通过而改变状态。I03—I06没有伪称真人或真实平台故障演练。

专业审核、批准、节点完成、发布、GPT审计和用户验收均不是模型输出字段可控制的状态。
