# 业务挂载接口与停止点

当前真实源工程只有飞书消息交付和合成 /doc、/progress 适配器，没有业务平台项目、节点、交付物的授权取数或挂载连接。本轮没有虚构平台目标、版本字段、批准记录、对象 URL 或成功回执。MissingBusiness 明确拒绝相应操作；整理、阶段稿和文件返回仍可独立使用。

LogicService 接受服务端注入的业务连接。该连接必须提供：

- resolve(principal, target_id)：先核真实用户和项目权限，再返回精确项目、节点、交付物、修订及状态记录。不能按同名自动选目标。
- sources(principal, target)：在取数之前按同一授权项目过滤，返回来源版本、文字位置和 provenance；教学资料不作为当前事实。
- commit(principal, target, content, content_hash, idem, guard)：提交前调用 guard，并在平台实际可用修订或指纹上执行比较更新；同一 idem 不增加第二个附件。不能从模型文字生成批准值。
- reconcile(principal, idem)：同样核权，只读核对原请求，返回目标、内容摘要、真实对象和可打开 URL；未知不得改写为失败或再写。

接口的模拟替身只位于测试代码，不在生产装配中使用。I02 正常挂载只完成合成替身验证，不能据此宣称实际平台挂载通过。需要的唯一接线输入是既有获准测试项目连接或源工程入口及其目标映射；本轮没有扩大权限、建立新项目或新增 PM 审批。

采用仅绑定当前候选内容指纹；目标和修订改变后只处理对应变更。未知写入由 /doc 对账 接续，撤销不删除已有对象。服务端保留原模型、身份白名单和项目权限职责。
