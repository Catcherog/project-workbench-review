## 3. UI 侧

UI R2 的最新 GPT 审核通过，B01—B04 分别关闭：批准稿完整保存且剩余决定可继续；无待发消息时仍可重入结果；四入口回执保持原上下文；撤销绑定事项并保护后续暂停/恢复及已发事实。

原 R2 的 32 项真实浏览器操作，属于在合成原型上实际点击、输入、刷新等验证，不能称为真实业务验证。GPT 核对源码、差异和执行证据，实际查看四张图并独立比对 4/4 指纹；没有重跑完整 32 项浏览器操作。用户最终交互验收仍待完成。

自然语言时间为原型匹配器，“明天下午”等可能落为 10:00，日期冲突识别有限。此限制保留为原型说明，正式整合应采用产品时间语义和回执。不要移植原型日期正则来替代核心功能，也不要为原型限制单开 UI R3。
