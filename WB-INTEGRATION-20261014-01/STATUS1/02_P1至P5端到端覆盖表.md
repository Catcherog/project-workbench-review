# 当前整合版 P1 至 P5 端到端覆盖

以产品本地提交 `ed23b67abd707abbca55d8aa5a010ccf9808b8e6` 为对象。每条记录连接业务结果、当前源码、UI 入口和既有验证。这里的“已实现”指代码路径和接线可定位，不推导整条真实业务已经完成。P1 历史验收保留；P2 至 P5 尚未整体验收。

共 148 条规则／场景追踪记录，包含共同约束和重叠场景，不用于计算完成百分比；另有 56 条代表场景交叉引用。完整结构化字段见 [coverage.json](evidence/coverage.json)。

状态分为实现、UI、验证和验收四列。当前未发现确认主干存在整块完全未实现或整块未接 UI 的依据；这不等于逐条行为已在新版完整验证。U03 至 U06 的体验收敛、准备结果的资料入口衔接、真实模型后段、同事链、持续运行与实际配置分别见缺口清单。

证据粒度逐项保存在 JSON：有同编号测试的列出原场景 ID；其他仅映射到相关测试组，明确标为未定位同编号的独立当前版本端到端场景。不得把“引用了测试文件”改写为该条全链通过。
