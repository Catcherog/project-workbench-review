# 能力边界与结论

| 能力 | 官方或本机依据 | 本轮结论 |
| --- | --- | --- |
| 本地主动接收飞书消息 | 已发布长连接配置；CLI 共享总线真实在运行 | 接收基础设施存在；没有真人测试入站 |
| 不新增上游连接的扩展 | 1 秒共享消费 ready/正常退出，前后总线 PID 不变 | 本机支持共享消费；未声称真实消息广播及无遗漏已验收 |
| 真实 Codex 执行 | 合成文件的真实命令读取、完成事件、最终 JSON | 本机通过；与飞书的完整闭环未通过 |
| 稳定身份 | 当前用户身份查询与唯一、未跨租户的同事查询 | 两个账号已定位，内部 ID 不公开；没有收到其真人事件 |
| 部门 | 两次用户身份查询分别返回非空部门标签 | 实际可读；不意味着机器人具有相同通讯录读取权 |
| 机器人读取用户资料 | A 返回 open_id/union_id 等有限字段；B 返回 API 41050 | B 为权限/范围错误，未通过其他身份绕过该次拒绝；A 未返回部门职位 |
| 职位 | 本次已成功查询结果均未提供职位字段 | 未取得，不能据此认定职位为空，也无法细分字段权限与接口表示缺项 |
| 岗位驱动权限 | 本轮未建设正式权限规则 | 未测试，不从部门或职位推导业务权利 |
| 多人、多轮及去重 | 两个合成人员与重启测试 | 模拟通过，真人未测试 |
| 目录读取限制 | 自有合成哨兵直接在 Codex sandbox 中运行 | 直接系统沙箱通过；完整模型执行路径补证不通过 |
| 自动加载与工具隔离 | 子进程最小环境，关闭外部能力，实际出现个人称呼 | 尚不满足真人远程调用前置 |
| 两种额外能力分流 | 主链通过后才允许增加 | 本轮未开展，保留为下一阶段 |
| Studio 移植 | 便携代码和说明已准备 | 当前 Mac 通过的结果不能继承为 Studio 已通过 |

本轮三个不同层次必须分开：官方允许定义读取权限；当前机器可执行系统沙箱拒绝测试；整条真人 Agent 链尚未满足前置。没有公开回调地址，也没有开通公网入站端口。

官方资料实读日期：2026-10-15。命令以本机帮助为准，Beta 权限配置需在目标机器重新核验。

- [Codex 非交互执行](https://learn.chatgpt.com/docs/non-interactive-mode)：用于结构化输出与程序化运行；本轮同时检查退出、完成事件和最终 JSON。
- [Codex 权限配置](https://learn.chatgpt.com/docs/permissions)：命名配置可约束本地命令的读写与网络；不能同时用旧 sandbox 参数覆盖它。不能据此推断 MCP、插件、启动时上下文也已隔离。
- [Codex 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)：配置和实际加载效果分开核验。
- [飞书 CLI 事件技能](https://github.com/larksuite/cli/blob/main/skills/lark-event/SKILL.md)：共享本机总线、ready 标记、有界消费与正常退出。公开 main 与本机 1.0.96 不默认等价，本轮另有实际兼容性测试。
