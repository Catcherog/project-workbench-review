# 本机 Agent 接入验证包 R1

本包是已执行的独立探针及受阻接入交接，真人入口关闭。先读 `00_当前交接.md`。

无需安装 npm 第三方依赖。环境：Node 22+（实测 24.21.0），macOS，已合法登录的 Codex CLI；本轮实测 Codex 0.162.0-alpha.17.2。跨版本与 Studio 必须重新核对权限配置支持。

```sh
npm test
```

上面只运行合成路由测试，不连接飞书、不调用模型。消息验证、执行、回复和回读均为显式测试适配器，不能计为端到端通过。

```sh
export PROBE_CODEX_BIN="/absolute/path/to/codex"
node tests/isolation.mjs
```

直接系统沙箱测试只使用合成哨兵与临时本机 HTTP 服务。模型和 API 均不调用。源码使用命名权限：默认不可读，仅系统最小运行路径和当前 job 目录可读；命令网络关闭。

```sh
node src/import-budget.mjs
node src/local-probe.mjs
```

这一步才进行真实模型调用，沿用本轮已核对的 `gpt-6-astra / max`，单次最多 180 秒；整包持久化限制 20 次和最多 2 个模型任务。仅操作者自行构造的合成输入可用，不能接入真人远程请求。机器认证留在 Codex 父进程；飞书凭据未传入模型子进程环境。

```sh
node tests/model-isolation.mjs
```

这是严格补证脚本，也会调用真实模型。本轮最后一次结果为 **断言失败/证据不足**：实际模型流缺少对应失败命令项，不能用最终文字声称通过。不要为了得到绿色结果放宽断言。

```sh
node src/start.mjs
```

预期退出 2，明确阻塞真人接入。没有运行中的飞书接收/发送适配器，也没有用配置开关绕过正式改造前置。`config.example.json` 仅说明拟采用的参数，不是已生效企业权限。

`src/broker.mjs` 使用 SQLite 保存去重、测试会话、预算和发送状态。模型不决定收件人和目录；恢复后 running/sending 保留为中断/未知，不自动重试。运行库应由一个 broker 实例独占，测试没有证明多个 broker 进程共享库的调度可靠性。真实传输适配器和后台生命周期管理留待正式分流方案获准后实施。
