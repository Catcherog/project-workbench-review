## 停止和恢复规则

broker 停止立即拒绝新任务并取消在途 IO/worker。进程管理只对自己 spawn 的 detached process group 发信号，250ms 后可升级 SIGKILL，最多1800ms确认；broker默认最多4000ms等候。操作系统检查不可用或进程未确认退出时，返回不确定，保留 owner/预算占用。不能因超时就写“没有残留”。

发送请求已发起但结果未确认：reply_unknown，禁止自动重发。收到可信发送回执但读回失败：保留 sent 和 reply_id。关闭后的迟到结果不修改状态或外发。崩溃 queued 转 interrupted_unstarted；人工检查原输入、旧窗口与副作用后，下一轮用新的明确请求处理，不能删除去重记录再投递。

单 broker 使用本地 owner 锁；第二实例拒绝启动。崩溃锁由 `inspectOwner` 检查 PID 与启动指纹后，才可用明确旧 owner ID 进行本任务本地恢复；不因 PID 数字存在就认定是原任务，也不删除未知锁。预算 `inspect/reconcile` 需确认旧owner和执行组均不再运行；旧 running 不自动释放。

本轮最终无在途真实模型、无测试事件消费者、无待发消息；直接网络对照的临时本机端点已关闭。正式服务无需恢复。runtime、private保留为本地证据，不进入迁移ZIP。

3. `node src/preflight.mjs` 只检查机器、架构、Node与实际SQLite、Codex版本/帮助、合法登录状态的安全摘要和本机接收进程元数据。默认不写、不调用模型/飞书、不连接总线、不安装软件或修改登录。`--write`仅保存预检结果。
4. Studio未运行本脚本前保持NOT_TESTED；运行预检也只证明环境，不证明真人端到端。
5. `node src/start.mjs`、`node src/local-probe.mjs`、`node tests/model-isolation.mjs` 当前都应退出2。B03前置未解决，包不会自行运行真实模型或开真人入口。
