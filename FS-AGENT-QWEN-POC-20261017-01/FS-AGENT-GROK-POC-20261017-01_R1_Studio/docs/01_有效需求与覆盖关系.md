2026-10-17 最新明确覆盖：用户改用本机 Qwen3.8 API，并指定复用原有 AM221D221；第二位测试者为第二位测试者。不创建新测试应用，不再安装或授权 Grok。用户已明确“沿用现有服务，不再创建账户”，覆盖原独立 macOS 账户要求，PoC 数据仍独立存放。用户允许申请状态和部门只读权限，需说明原因并交管理员审核；后续补充“发申请前告知我”，以后先说明具体内容和影响再提交。

## 目标与范围

部署于一台保持登录、不休眠的 Mac Studio。PoC 合成路由只对用户和第二位测试者开放。先跑通“飞书输入 → 既有入口分发 → Python 网关 → 本地 Qwen API 真实推理 → 飞书结果”，只有两个合成适配器，不连接真实业务系统。现有 AM221D221 普通私聊的使用范围保留；它的既有验收不能代替本次 PoC 验收。

## 仍有效的用户决定

### 飞书入口与路由

- 复用既有企业自建应用 AM221D221 的单条长连接；新增测试私聊、测试群内 @、菜单、选择和切换。未配置测试群时保持群入口关闭。
- 预设按钮及 /doc、/progress 指令，不让模型分类意图。未选择时只显示菜单，不调用模型猜测。
- 选中 Agent 后，同一会话后续消息交给选中 Agent，直到切换或 /menu；`/chat` 返回既有普通聊天。富文本 `post` 目前被拒绝，是真实 `/doc sample` 未入队的首要待修项。
- 回调在 3 秒内完成轻量记录；模型、通讯录、文件上传及消息发送放后台。只在收件成功持久化后认定已受理。
- 回调操作者按飞书真实身份重新核权，不能信任卡片参数声称的用户。
- /doc 由模型整理输入，Python 用固定模板生成 Markdown 文件；/progress 使用固定合成进度。权限、路径、发送目标由网关决定。

### 权限与输出归属

- 部门规则与个人白名单同时满足，外层再套两人硬白名单；默认拒绝。
- 身份及部门以飞书通讯录为准。入队、执行、交付前重新检查；刷新失败拒绝相应操作。
- 用户调度键不带 chat_id，同一人跨群、私聊、Agent 的执行统一受每人 1 限制。
- 群内只发状态和简短结论；填好的文件及详细结果私聊给原提问者。合成项目进度可按固定允许字段发群。
- 不主动联系同事、不扩大名单；真实测试参与和具体用户标识必须准确，不凭姓名猜 open_id。

### 状态、去重、恢复

- SQLite 为任务唯一依据，WAL、短事务；内存队列只唤醒。
- 消息去重以 UNIQUE(app_id, tenant_key, message_id) 为依据；平台重推、用户重试、已有结果重发分别处理。
- 结果先持久化，再从待发送记录交付；卡片更新按版本串行。
- 每次执行有独立编号；超时终止本次客户端的整个所属进程组并确认退出，迟到结果拒绝。客户端停止不证明共享 Ollama 请求停止；无法确认时保留 stop_unknown 并暂停 PoC 新推理，不停止其他用户使用的模型服务。
- 重启：运行中任务标为中断，不自动重跑；已保存结果继续交付；发送状态未知先核对。
- 认证失效、额度耗尽、限流需要区分，暂停受影响的新推理并保留状态；通知只向明确配置的用户接收身份发送。无法发送时保留本地状态待恢复，不承诺断网即时通知。
- 本轮无人值守只要求进程崩溃后自动拉起；Studio 保持登录、不休眠；断电恢复后置。

### 24 小时与个人隔离

- 上下文键为 tenant_key + app_id + chat_id + open_id + agent_id。
- 从每条消息原始入库时间起绝对 24 小时；聊天、复制、重试不延长旧内容有效期。不得用新时间重新保存旧消息以续期。
- 清理覆盖任务正文、上下文副本、生成文件、待发送正文、临时会话和日志；审计仅留必要元数据。
- 到期内容不得读取、加入上下文或重新交付。不要把逻辑过期等同于全部存储介质上的物理不可恢复。
- 不提供用户查看/删除记忆的入口；后台按期处理。
- 不读取、修改、导入个人记忆、个人规则、个人认证；不给模型个人目录、个人浏览器、个人连接器权限。每任务客户端请求、输出和临时副本必须按服务规则清理；未知请求仅保留无正文状态。
- 不把真实机器人正文或个人资料贴回 Codex 开发对话。

## 历史评审提供的实现参考

以下是来源助手的补充建议，按当前主线需要采用，不能据此新造复杂前置审计或要求用户重新确认已确认原则：

- 入队即固定 Agent 与原会话；之后切换不改已排队任务。上下文不含未来消息。
- 选择状态与 Agent 记忆分开。群无 @ 忽略；裸 @ 显示菜单；前缀可以同步选择。
- 卡片操作独立去重，绑定真实操作者、会话、版本、目标任务、有效期；旧卡片不覆盖新状态。
- 私聊失败不把详细正文或附件补发到群。群任务私聊交付不合并群与私聊记忆。
- 执行/详细交付前刷新权限，失败拒绝；测试群使用明确白名单。
- 排队时间含待鉴权时间，重启不重置；进程停止未知时不释放执行资格，不允许该任务重试。
- 单实例保护，清理只操作服务拥有的进程组；未知发送状态保持未知，不盲目重发。
- 队列数量上限“每人 2、全局 4”、元数据 7 天仅为历史建议默认值，尚非用户已确认参数；按最小实现需要做成配置，不能冒称已批准。
- 历史助手关于特定 SDK、CLI、SQLite 版本或产品政策的文字需在 Studio 用本机实测与官方资料核实。当前包未锁定这些版本。

## 最小交付判断

P1/P2 必须有真实本地 Qwen 调用与飞书结果证据。当前账户 API 连通测试不替代最终运行环境 P1；既有普通私聊不替代 PoC /doc 验收。模拟执行器、离线测试或已写配置均不能替代。P2 成功即向用户给机器人入口、命令、预期结果和实际模型；再补 P3/P4。两路失败保留单路并标未通过，其他普通缺陷不阻塞主线。
