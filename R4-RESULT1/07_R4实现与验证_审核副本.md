# P1 本地实现与验证 R4

批次：S1P1-20261012-01-R4-RESULT1；需求v0.3-exec1；源码提交 `7b03f0ebbcfc9172fc4d8da02c2bf362112b7e42`。本报告的“通过”均限于标出的本地验证层级，不是正式业务验收。

## 1. 用户现在能走的流程

从原数据／风险列表打开事项，选择“记录进展 / 讨论”，在同一输入框提交明确事实、问题或二者；框下检查和完成区域直接可用。只改时间可以发送，选择过程不写库。进展缺时间照样保存，回执可补安排或目前都待定。旧等待区域转到这一套控件，避免两份时间表单。

普通成功返回原列表；混合输入保存明确部分后留场看建议。风险解除但仍有工作保持跟进；明确结束进入同页已结束。撤销恢复整次提交实际涉及的值，重新打开只恢复后续办理，两者分开。
