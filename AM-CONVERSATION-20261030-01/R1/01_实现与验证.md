# 实现与验证

## 已实现

| 能力 | 当前行为 |
|---|---|
| 自然私聊、原群 @ 对话 | 按用户、群、线程及项目范围隔离；明确引用 AM 群回复时继承可见项目，不借用另一人的私聊记忆。 |
| 项目事实 | 精确编号、别名、近期焦点；同轮代码提前检索，模型只拿获准资料。大信息记录按字段提供，保留省略说明、时效和覆盖缺口。 |
| 工作记录 | 跨天保留明确登记的事项、项目与版本；原始消息和渲染副本最多 24 小时，未批准且过期的动作草稿清除正文。工作事项不等于正式项目计划。 |
| 跟进与反馈 | 原事项库登记、暂停、恢复、核验、关闭预览；本人被指派事项可自然反馈。自报、材料提交、核验和专业验收分开。 |
| 发送 | 原机器人及原获准群/成员，或本人私聊；完整文本预览，实际回读后才接受确认。重复确认不重发，结果未知先对账。 |
| 提醒与简报 | 原调度器的一次、每天、已核实工作日规则；查询、暂停、取消、改时间/正文；订阅先完整预览确认。群定时通知支持文字及真实 @。 |
| 文稿 | 查询稿件、建立独立新稿、逐字补资料、原链路附件、生成排队、查看审核、采用版本、预检、选择目标、云文档和挂载预览。可选标准后端复用同期文档模块。 |
| 项目反馈 | 保留当前输入原话与来源进入原提案库；本人可复核收为私有项目知识。本轮没有开放台账写回。 |
| 知识学习 | 规则、案例、风格与事实候选；自然批准、修订和版本记录。没有微调或替换模型，也不使用个人 ChatGPT 记忆。 |

## 验证口径

原包在本机最初 136/137 通过，唯一失败为 macOS `/var` 与 `/private/var` 的路径别名断言。已在主动使用的副本修正路径比较，收到的原包保持不变。扩展后对话包 138 项通过，原工程相关组 275 项通过，总计 413 项；原始日志和 JUnit 在 `evidence/`。

新增检查覆盖：旧命令仍可用、发送预览先回读、重复确认、发送未知不重发、提醒修改后版本更新、取消无提前发送、知识批准、超大信息按字段提供、两稿并存、反馈不写台账、群引用与用户隔离、简报订阅和到期清理。

模型调用使用原协调器和原跨进程锁。对话最多两个后台任务，为原查询保留工作槽；单请求有总时间、轮数、工具数、输入/输出预算。实际模型失败不会自动重跑未知请求。

### 复现

本审核包 `source/` 是完整脱敏快照。对新的空目录运行 `scripts/reconstruct_review.py`，使用原 Python 3.12 依赖，执行该目录 `AM-CONVERSATION-20261030-01/R1/scripts/run_affected_tests.py`。对话包运行 `am-conversation-r1/scripts/verify.py`，将 `AM_REFERENCE_ROOT` 指向重建目录的 `reference_am`。历史补丁测试验证的是收到包的固定 UX3 基线；当前接入以本包实际源码为准，不能把历史补丁直接覆盖现工程。

独立重建只启动测试替身，不启动第二个飞书消费者，也不读取真实业务配置。
