Copy a Base resource (not a BaseApp)

Usage:
  lark-cli base +base-copy [flags]

Flags:
      --as string             identity type: user | bot
      --base-token string     base token
      --dry-run               print request without executing
      --folder-token string   folder token for destination
      --format string         output format: json (default) | pretty | table | ndjson | csv (default "json")
  -h, --help                  help for +base-copy
  -q, --jq string             jq expression to filter JSON output
      --json                  shorthand for --format json
      --name string           new base name
      --time-zone string      time zone, e.g. Asia/Shanghai
      --without-content       copy structure only

Risk: write

Tips:
    • BaseApp/AppMode copy is unsupported. Do not pass an app_token or use this command as a substitute.
    • Example: lark-cli base +base-copy --base-token <base_token> --name "Copy of Project Tracker"
    • Use --without-content when the user wants only structure.
    • If copied as bot, output may include permission_grant; report it so the user knows whether they can open the new Base.
