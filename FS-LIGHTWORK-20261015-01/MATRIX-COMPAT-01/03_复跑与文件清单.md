# 复跑与文件清单

Node.js 18+；聚合及离线测试没有外部依赖，不需要安装新框架。

在此目录执行：

```sh
node --test tests/*.test.mjs
node src/replay.mjs
node src/read-live.mjs
node src/verify-evidence.mjs
```

- 第一条只用合成数据。
- 第二条需本机 `evidence/` 内的既有接口快照，只重放，不联网。
- 第三条只读固定真实测试对象，需现有 Meegle 登录与本机 `input/read-scope.json`；不切换登录、不扩权、不自动登录。每次输出独立 `evidence/live-*` 目录，不更新源记录、不维持常驻进程。
- 第四条核对本轮固定基线及8小时样本。以后源记录确实变化时可能失败；应解释变化，不能为了通过断言修改来源。

## 代码

| 文件 | 用途 |
|---|---|
| src/aggregate.mjs | 候选行级读取、版本去重、周/月归组、来源覆盖与异常输出 |
| src/read-live.mjs | 一次性真实只读→独立适配 |
| src/replay.mjs | 原始接口快照重放 |
| src/verify-evidence.mjs | 前后值和本轮对账核对 |
| tests/aggregate.test.mjs | 26项离线边界测试 |
| source-baseline.json | 云端v6定位与原源码缺口；不宣称是原组件代码 |
| evidence/code-version.json | 本机独立代码基准与结果完整SHA |
| evidence/implementation.patch | 独立代码及文档差异；不是原组件补丁 |

公开目录内 input、baseline、evidence 均为经过脱敏或必要字段投影的审核副本；原始文件与固定真实对象清单留在本机。纯逻辑测试可直接运行；src/replay.mjs 和 src/verify-evidence.mjs 在本公开副本上只处理脱敏数据。src/read-live.mjs 缺少执行端私有清单与登录，不能在公开环境执行真实读取。

当前没有本轮周汇总的网页预览链接；原发布页只供查看原月度设计。未启动本机 HTTP 服务，因此不存在可用但被遗漏的测试网址。

GitHub 目录逐文件提供代码、合成测试、脱敏接口快照与现场原月度组件验证截图。截图仅有已核实的虚构项目和工时；没有账号身份、URL或凭据。公开文件校验以 manifest.json 为准。执行端会另存固定提交逐文件读回回执；这不等于GPT已经独立审核。
