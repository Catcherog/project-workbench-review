## 保留的架构约束

1. 继续使用原机唯一飞书连接。群聊 @、机器人私聊和被动工作私聊分别受理；被动私聊默认只协助本人，不将第三方消息转化为本人操作授权。
2. 来源采集与任务触发分离。自身回复、非受理消息仍可保存来源记录，不生成循环问答。明确非工作消息与尚不能确定的消息分别保留结论。
3. 明确查询走规则快路径，不为项目名等回答缺项强制分类。专项产物、业务修改和额外外发优先判断；复合要求保留原文和未处理动作，第一期只选一个执行分支。
4. Grok Bot 仍为外部执行者。文档、项目、工程 Agent 只登记契约，默认待接入。共享信息、事件恢复和路由实现复用网关 SQLite Store，不新增知识平台，不训练模型。
5. 读资料、业务写入、发送分别授权。工具包装层候选并不能约束 Grok Bot 尚未接入包装层的直接凭据和记忆。本轮不宣称已实现外部执行器的端到端权限硬隔离。
6. 交接、持久接单、开始执行、运行结束、结果交付、独立回读分别记录。Webhook 200、同一线程、模型自报完成都不代替完成证据。

## 复审修订后的可靠性契约

事件与游标在同一事务保存，`h1_inbox` 同时记录待处理责任。事件重复只去重存储，不抹去未完成的处理。纯路由计算在事务外执行；计算结束后按认领 token 和来源版本提交，进程退出后可以恢复。故障注入覆盖“事件与游标已提交，任务尚未建立”后进程真实退出。

任务与待派发项同事务提交。唤醒前在同一事务取得执行范围及代次，稳定业务操作身份不随路由版本、尝试编号或重启变化。未接单队列保存原始截止时间；超额显示积压状态，过期显示未执行，重启不重置预算。已接单、租约过期或发送结果不明的任务保留核对责任，不自动重放。

| 字段类别 | 冻结和变化规则 |
| --- | --- |
| 业务语义 | 原始要求、意图、目标资源和项目参数、授权主体、回复目标、附件身份构成业务指纹；开始派发后冻结 |
| 传输 | 投递尝试、路由版本、追踪及文件位置不进入业务指纹 |
| 上下文 | 派发前构建有界快照；接单后保留实际版本，不能重送时静默替换材料 |
| 权限 | 使用时重新检查；策略版本可递增并收紧，不能借刷新扩大范围或产生新操作 |
| 请求修订 | 待确认补充继续原任务；已有业务效果的修改保留修订，先核对旧效果，不能一键重新开始 |

状态事件用事件身份去重。终态不被迟到进度覆盖；状态未知可被有效证据纠正；矛盾终态进入冲突；旧代次仅记证据，不释放当前资源。运行结束需要关联实例和实际停止依据。未决的执行器发送仍阻止安全接替。若以后增加进程终止能力，须核验 PID/进程组或 run_id 与 epoch 的真实归属，不能用任意 kill 或超时布尔值代替。

## 查询和补充信息

信息项保留来源版本、项目、性质、可读主体、披露受众及派生依据。正式记录、预测、客户要求、执行声明、已核验结果分别保存。普通原文采用抽取式保存，关联不明的消息只保留来源，模型不猜项目。

本人补充在授权与项目校验后同步提交，再异步更新视图。后续查询采用“已有视图 + 未入视图增量”，校验最低可见版本。默认最多 40 条增量、快照不超过 16 KiB；超限明确 `view_lag_warning`，使用同任务权限补查。该限制是工程配置，不是性能保证。

派生摘要继承所有来源的交集权限。读取和发送前检查来源是否仍可读及版本是否有效。编辑、撤回、删除和显式撤权使相关资料失效。消息、文档、附件、项目字段、评论和权限变更的真实采集覆盖分别记录；本轮只实读本人 AM 会话、一个既有披露群各两条最近消息及已批准群目录。

## 分类器和权限边界

本机模型目录确认标识 `gpt-6.1-terra`，通过已安装 Codex CLI 的登录通道完成一次合成分类；没有假定独立 OpenAI API 密钥。传输用独立临时工作目录、结构化输出、只读执行配置，并关闭本次可配置的 shell、应用、记忆、浏览器和子代理功能。输入只含当前消息及附件元信息，来源文字不作为权限或系统指令。

默认分类预算仍为 6 秒、最多一次明确短暂故障重试，第二次只使用剩余预算。首次冷调用 6 秒超时；独立 30 秒诊断中最终一次返回用时约 9.36 秒。没有据此宣布 6 秒或 P95 目标达成，未启用生产分类。真实传输观测中存在一个 CLI diagnostic error item，保留计数；最终消息满足 Schema，不将该诊断抹成零错误。

任务工具包装层拒绝业务写入、错误发送目标、旧代次及已撤权资料，允许已授权目标的本次回复。它只证明所有调用经过该端口时的代码边界。本轮 Grok Bot 没有绑定该端口，不能将包装层测试通过外推为 Bot 的权限、记忆或缓存已受约束。

## 回退和指标

回退先停指定范围派发，形成已完成、未派发、结果不明三类清单。旧轮询必须导入完成及未决排除项，为每个未派发任务分配唯一承接方；未结束的冲突实例存在时拒绝恢复。不能以切换时间统一跳过历史，也不能恢复旧数据库快照丢失效果记录。本轮完成的是清单和核对代码，真实 Grok Bot 五分钟轮询尚未完成状态导入验证。

保留 `T1=t_i-t_m`、`T2=t_r-t_i`、`T3=t_a-t_r`、`T4=t_p-t_a`，排队包含在各段内；结果观测延迟另计。ACK 缺失时 T3/T4 缺测，负值保留，首条有效回复与完整要求完成分开。充分回答、部分回答、待澄清、资料缺口、能力不可用和失败分别统计。样本少于 20 不输出 P95，成对对照按逐对差值计算附加耗时。
