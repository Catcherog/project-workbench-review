## 最小复现

在包含 RESULT1 的源码基点 `7b03f0ebbcfc9172fc4d8da02c2bf362112b7e42` 的独立工作树应用 [增量补丁](04_产品增量_R4-FIX1.patch)。本审核仓库仅装载审核材料，不是完整可运行产品仓库。使用 Node 24 与项目已有依赖：

```sh
npm run build
npm run typecheck
npx eslint app/work-item-entry.tsx app/work-item-time.tsx lib/work-item-progress.ts scripts/work-item-entry.mjs scripts/test-s1p1-fix1-domain.mjs scripts/test-s1p1-fix1-browser.mjs
PM_S1P1_OUTPUT=output/s1p1-r4-fix1-20261013 node scripts/test-s1p1-fix1-domain.mjs
PM_S1P1_OUTPUT=output/s1p1-r4-fix1-20261013 node scripts/test-s1p1-domain.mjs
PM_S1P1_OUTPUT=output/s1p1-r4-fix1-20261013 node scripts/test-s1p1-http.mjs
PM_S1P1_OUTPUT=output/s1p1-r4-fix1-20261013 node scripts/test-s1p1-fix1-browser.mjs
```

浏览器脚本需要可用 Playwright 和 Chromium；可通过 `PM_PLAYWRIGHT_MODULE` 指定 Playwright 的 package.json，`PM_CHROME_PATH` 指定浏览器可执行文件，均为测试运行器路径。`PM_FIX1_CASES=F06-UI` 可只跑 F06 和隔离边界，用于补拍时区画面；补拍未重复计入 69 项。既有 `test-s1p1-browser.mjs` 已在原本机运行环境复跑 16 项，不重传其未变源码。
