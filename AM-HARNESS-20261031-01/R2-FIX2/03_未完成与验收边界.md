# 未完成与验收边界

本轮为四项限定补修，不自动关闭原通用目标、专业异步流程与精确依赖未完成项。独立复审通过、整体启用、本人亲测、手机、独立人员及正式业务验收仍须分别取得证据。

| 项目 | 本轮支持范围 | 继续保留的边界 |
| --- | --- | --- |
| 稳定目标与回执 | 明示事项拆分、原调用身份、原生创建回执独占、未知结果屏障 | 任意自然语言目标、更正重规划、复杂依赖与专业异步完成通知未通用闭合 |
| 原提交恢复 | create_followup 的原生操作记录只读核对；已有外部批准及发送对账保留 | 其他本地工具的未知提交仍按原回执契约处理；没有凭据不推断失败，不自动重放 |
| 事实覆盖 | 宿主固定必要事实及允许省略集合；实际语义陈述覆盖 | 相关事实选择仍为有限查询规则，不能声称任意自然语言需求范围已完整理解 |
| 语义表达 | 明确负责人/进展关系及已支持限定 | 任意专业语义、多来源推断、全部表达形式未证明；不确定继续回退 |
| 共享事实 | 沿用查询/文档共享 EvidenceBundle | 知识、内部工作记录、专业异步产物等尚未全部纳入统一原子事实合同 |
| 精确依赖 | 沿用现有影子比较、全局来源守卫 | 平台继承权限、集合水位、负向查询完整性仍缺证据，未放宽全局守卫 |
| 模型评估 | 本轮按源码版本新增定向观察 | 定向小样本不代表原 48 场景总体验收；旧业务失败与未评项保留 |
| 自然度 | 保留旧 48 项首轮盲评材料及 10 项可呈现配对 | 未评分，不删去其余 38 项，不把技术拒绝/投影候选计为自然度成功 |
| 真实业务 | 仅必要维护和运行状态核对 | 未扩大真实业务验证范围；合成投递回读不能冒充真实飞书发送 |

运行保持 response=legacy、旧重写 off、goal_tracking=false、600 秒身份、ledger_write=false。原 Qwen、原协调器和唯一消费者保持。27 项既有工程失败继续记录，不列为本轮已修复。
