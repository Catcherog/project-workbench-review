## 4. 为什么不在本包加入新的厂商 SDK

当前优先问题集中在应用 harness：入口控制被长任务挡住、明确查询仍付出模型往返、任务状态与输出提交缺少统一版本绑定。保留现有 Qwen/AM 后即可改善这些点。引入另一套 runtime 会增加模型协议、插件授权、会话持久化和消息投递之间的衔接工作，并不能自动保住原批准、thread、来源和 outbox 语义。

因此本包交付的是模型无关的增量模块及真实原引擎补丁。后续可在同一合成/真实评测合同下，用隔离适配器对比 OpenAI 或 DeepSeek runtime；是否替换模型、迁移平台和改变费用，属于另一个有独立实测依据的决定。
