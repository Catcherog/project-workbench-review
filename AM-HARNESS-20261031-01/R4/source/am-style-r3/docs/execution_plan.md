## P1：自然输出与 Qwen prompt-only

以新的 frame hash 建立一个独立批次，旧 26 条仅作开发回放。先运行有限数量的代表性正常场景和破坏性候选：

- 正常：负责人、实际进展、发送成功、取消保留历史、事项保存但提醒缺时间、部分成功/另一项未知、真实重试、资料不全。
- 语义边界：否定、预计、阶段/时间范围、同名不同项目、责任人错配、没有回执却说成功、原预计时长被误问为提醒时间。

先修 start_time/duration 的宿主生产端；调用 `with_natural_surfaces` 是新 prompt 实验，不能重写旧 frame 或把旧人工认可搬过去。通过原协调器调用当前 Qwen，保存 logical/wire、模型 digest、原请求、原响应、verdict、fallback 和实际时间点。

默认生产 off；隔离实验或 shadow 的 mode 要单独记录。首轮建议每类1个场景、另做独立实体变体，作为开发观察，不宣称统计代表性。模型执行次数、资源窗口与实际未完成原因如实回传。

**完成条件：**分别报告 JSON、宿主语义、自然度人评、实际采用、耗时；未知保留未知。新增模块的有限语法覆盖不是 Qwen 权重效果。
