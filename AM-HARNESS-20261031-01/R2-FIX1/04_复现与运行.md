# 复现与运行

## 隔离回归

使用原工程 Python 3.12 及已安装依赖。系统 Python 3.9 缺少本工程依赖，不作为原环境回归结果。

```sh
python scripts/run_checks.py --source source --output /tmp/am-harness-r2-fix1-review
```

完整工程存在 27 项既有失败，脚本真实退出码为 1。比较名称、状态、错误信息与断言位置，不隐藏退出码。会话 verify 与 pytest 重复覆盖同一组用例，不能累计；脱敏重建也是同组复跑。

## 固定模型评估

input/evaluation-manifest.json 固定 48 项种子、资格规则及三次成对测量；input/evaluation-lock.json 固定执行源码及工装字节。表达预检的 12 组输入由真实生产工具在合成外部接口下生成，不额外复制 synthetic_receipt。

主循环试验通过原消费者的私有验证队列调用原协调器，业务工具和数据库在隔离环境运行，外部平台接口为合成。新验证操作只传输有界模型请求，不执行业务工具、不发送飞书消息，不创建消费者或供应商通道。

执行器退出成功只表示观察记录已写出；业务完成、正确停点、语义、采用、投递与自然度须分别读取。真实停止不明会停止继续入队并保留原暂停，不自动清理或重放。

## 运行与停用

生产默认 legacy，原 output_rewrite 为 off，新增目标执行开关独立且未开启。快查、控制和短回执维持确定性路线。只有任务族取得所需证据后才讨论启用。

原维护脚本检查当前源码、并行修改、唯一消费者、任务/投递空闲和原模型租约；只更新原桥接源码，保留配置字节及业务数据库，核对加载指纹。不得用 source/ 审核副本覆盖真实配置、数据库或后续代码。

回退表达使用 legacy，停止新评估入队；附表仍正常到期清理。保留已提交事实、批准、采用、回执和未知结果，不靠重放业务修补记录。

本次 stop_unknown 的恢复脚本仅适用于已核对的这次模型验证请求，必须满足模型已自然卸载、原推理进程已结束等前提。它不是通用清除暂停或重试命令。原未知记录已私下保存，不包含在公开审核材料中。

## 最终增量及观测来源

正式 48×3×2 的测量源码为 e86a4433，最终源码为 f767cea9。后者只增加目标回执恢复修正及其反例，完整回归和补充模型观察分别记录；没有用旧模型输出冒充新源码重跑。

原生计时、工具调用次数和回复状态从本次已关闭的合成测试库只读提取，并与相应输入及运行记录核对。公开包保存结构化摘要及原库指纹，不含这些数据库文件；时间戳使用合成场景时钟，stage seconds 使用实测单调时钟。不得将合成时间戳当真实平台收发时刻。

公开模型请求封装和证据均做脱敏，EVIDENCE_SHA256.json 分列原始与公开字节指纹。原提案、原快照的指纹保持原值，不为脱敏文本补新业务 hash。公开件用于审核，不能当作新提案送入真实运行。

如需核对正式实测源码，可在独立审核目录复制 source/，反向应用 MEASURED_TO_FINAL.diff，并逐文件核对 MEASURED_SOURCE_SHA256.json。该补丁只描述测量版到最终版的两个文件增量，不用于运行树回退或覆盖。
