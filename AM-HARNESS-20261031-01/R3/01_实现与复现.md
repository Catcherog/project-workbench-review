# 实现、验证与复现

独立 `OutcomeCollector` 使用自己的 ContextVar，复用原 R2 结果适配和回执合同。原 `ResponsePipeline.begin()` 在 legacy 下仍返回 None，任务模型不会因为新 collector 而启用 response_plan。成功、失败、控制和预取结果都经同一记录钩子进入 collector；同事件重放保留原 terminal_json，不重新调用表达模型。

普通任务在 `_finish` 保存历史前独立表达，共享原 deadline；独立 fastpath 和普通 handle 内 fastpath 均显式禁止模型调用。projector 只处理完整有界字段；未识别语义限定直接回退。只对闭合的单项目完整字段查询移除旧通用目标尾句，复杂动作与保护正文不擅自简化。末端 schema/语义、过期、权限、取消、revision、generation、依赖指纹和原 outbox 事务前复查分别保留。原原子 outbox 仍是唯一发送通道；本轮未实际投递新表达。

`am_style.prompt.coordinator_messages()` 统一原 Qwen native_chat 的实际外层 user 消息。真实对照与 gold 导出以保存的队列请求核对相同封装。Codex dotted-key 引用方式按本机 CLI 预检修正；无工具证明仍不满足，未伪造 capability proof。

## 复现

本包 source/ 是相对固定 R2-FIX2 source/ 的最终增量，非生产安装包。先在隔离目录运行：

```sh
python scripts/reconstruct.py --baseline ../R2-FIX2 --overlay . --output /tmp/am-r3-review
```

脚本校验基线与本轮 audit SHA 后合成源码并复制既有测试夹具。使用原 Python 3.12 依赖环境，运行 `scripts/run_checks.py --source /tmp/am-r3-review/source --output /tmp/am-r3-checks`；原工程应保留 27 个既有失败。补充运行 `PYTHONPATH=/tmp/am-r3-review/source/am-conversation-r1/src:/tmp/am-r3-review/source/am-style-r3 python -m unittest discover -s /tmp/am-r3-review/source/am-style-r3/tests -v`。公开包不含原私有评分，其专用检查会跳过；本机该项与全部 99 项已通过。

首次原工程复跑因沙箱回环端口/子进程限制另有 8 项错误；解除该测试环境限制后回到 798/27。最终会话 206 已包含本轮 13 项，不重复累计。训练首次入口受 Q8 驻留资源守卫阻挡；可用内存回升后在原模型租约下保留 Q8 驻留，MLX 上限 22 GiB。首个实际加载试验发现 grad_checkpoint 参数类型错误，优化步为 0；修正为 layer 实例后另存 v2 单步结果，旧失败记录保留。

维护使用本轮 install_current.py；保留既有空闲、配置、源码、唯一消费者、原租约、停止未知检查和已证明过期只读标记例外。没有清理未知业务、重放任务、停止 Ollama 或更换模型。安装及独立回读记录见 evidence/。
