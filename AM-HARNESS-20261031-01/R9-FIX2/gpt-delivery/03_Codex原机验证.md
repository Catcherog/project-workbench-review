~~~text

~~~

检查状态：

| 状态 | 下一步 |
| --- | --- |
| ready | 所有修改前文件匹配；可在隔离工作副本应用补丁 |

| partially_applied | 部分已合入；只处理剩余差异，不重放整个补丁 |

## 6. 来源绑定场景

先在隔离库和合成目标确认破坏性状态变化；涉及真实来源的撤权类场景沿用现有授权范围，不能为测试擅自调整用户的真实访问权限。

| 场景 | 预期 |
| --- | --- |
| 连续采集只有成功轮询心跳 | 同一业务依据仍可生成并发送 |
| 显式 freshness 不变，调整纯轮询/对账频率 | v2 可继续；记录前后摘要 |
| 无关来源 ACL 改变 | 当前 v2 文稿可以继续，普通/v1 仍用原全局规则 |
| 共享台账增加/删除无关项目 | 当前项目 v2 不失效 |
| 相关来源撤权后恢复 | 已有稿件仍失效，重新捕获才可继续 |
| 当前项目移出又移回来源范围 | 原绑定失效 |
| 相关原文、事实权威、缺口或未解析消息变化 | 原绑定失效 |
| 原文或身份租约到期 | 拒绝，缓存不能续期 |
| 旧版本 writer 只推进全局版本 | 保守失效，不能当作已证明无关 |
| 缺失/降级 view 或 scoped marker，正文/TTL 被改 | 拒绝普通卡片及纯文本完成通知 |
| 信息核验器不可用 | v2 完成通知不发送 |

记录检查入口、原绑定、分项摘要差异、稳定错误码和结果。公开回传只需合成数据、哈希和必要状态；真实业务原文和人员标识继续留在已授权原机位置。
