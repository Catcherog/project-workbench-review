# 当前身份 成员范围与隔离核查

本轮从指定 AM 机器人审计聊天读取交接，随后通过原会话的下载控件取得 DIRECT-DM-01 v1.0-exec 原件。附件 SHA-256：`0f5c6bdf67fe315b0217c60a735e7a50cbade5f31a0c43c189d556242ab9b4f8`。聊天读取工具返回 attachments 为空，但已从真实页面下载原件；未用本机同名文件代替云端读取。

输入截止为审计聊天 DIRECT-DM-01 交接和本轮直接指令。工时聊天中已撤销的测试鉴权要求不是本轮授权依据；本轮使用新的明确私信测试指令。未读取其他无关聊天。

## 当前事实

本轮复用既有受管 CLI 和当前身份，未切换账号。当前用户、负责人应用所有者与摘要接收人的同应用标识匹配。参与人 B 按既有 ID 定向读取，唯一、激活、非跨租户；显示标签前缀与旧记录不同，同应用 ID 未变。未使用显示名重新绑定。

`check_white_black_list` 仅查询 A/B 两个已有 ID：B 三项均 false；A in_white_list=true、in_black_list=false。查询返回 ok=true，不能再表述成“成员范围未知”或“缺搜索权限”。官方规则是白名单或付费白名单为真且黑名单为假才可见。[官方查询说明](https://open.feishu.cn/document/server-docs/application-v6/admin/check_white_black_list)

online_version_id 与读取发布版 ID 一致，版本 1.0.7。负责人机器人信息仍对应 APP_OWNER。未查询任何工程师候选机器人。授权搜索范围不是本轮前置。

目录返回的 p2p_chat_id 属于当前用户视角，未证实为 APP_OWNER 与 A/B 的机器人私聊，故没有用于本轮可信会话绑定，也没有通过发送消息来探测。

## 正式路径核验

事件桥在当前身份后可能读取消息、写 sources，再触发 CoreFeishuInput。私聊/@轮询经 PersonalMessageReader 与 AgentMonitor 写 sources；群发现可由 @触发扩展读入。LocalStore.save/insert 是最终持久化处。CoreFeishuInput 还可重新启动预算等待的输入及自动回执，因此本次候选补上这两个下游阻断处。

本轮读取服务状态、消费者状态与相关源码；没有执行 poll、scan、外发或正式配置变更。原 2 个消费者仍在；本轮新增 0。元数据计数和正式源码指纹不等于已经证明真实测试数据不会入库。

原始身份、可用范围返回、进程与界面证据仅在本机 private 保留；公开 `readonly-facts.json` 使用 A/B 别名，不能从公开包还原完整个人映射。执行端只读事实与 GPT 独立复审分列。
