**候选未安装，当前只供独立审核。** `proposals/direct-dm-isolation.patch` 对读取时正式字节基线生成，不覆盖并行改动。修改 7 个既有文件，增加 1 个模块，未修改业务字段、项目、工时、排期、现有消费者或 UI。

| 文件 | 候选变化 |

| scripts/direct-dm-isolation.mjs | 独立 SQLite 的不可变请求、消息隔离记录与外发意图；隔离不依赖 worker 在线。确认验证与外发额度仅通过可信本机接口，模块不包含网络发送。 |

## 尚未满足的正式接线

现有正式服务没有本模块。本候选未提供完整实时发送 worker、可信批准记录导入、机器人 p2p 会话取证或完整服务启动验证。不得通过手填 true、合成人员事件、测试密钥或未核实的 p2p ID 补足。候选 state machine 的模拟 port 验证只说明离线合同，不能作为真人门禁事实。

发送前必须有本机持久化的真实 app/tenant/人员/两段机器人 p2p 会话、准确模板 hash、固定合成摘要 v1、五分钟窗口、随机请求 ID 和一次性码。请求 ID 和正文前缀只能触发隔离，不能授予执行权。有效确认还需真实 user/p2p、引用原预览、原消息回读完全相同及当前批准/权限版本；每类外发先持久化唯一意图，未知不重发。

窗口内绑定会话的消息会暂存隔离；停测后保留窗口和已用请求、消息/引用关联。未来同人同会话中无关联的正常消息可继续走业务路径。任意晚到、没有引用或请求标识的自由文本无法判定是否本测试，因此当前不能承诺全量正式零污染。需要审核接受“所有测试回复引用原预览”的协议边界，或准备更强的原生会话隔离后再申请安装；没有通过则不发送。

## 具体批准边界

成员提案仅 `add_visible_list.user_ids=[PARTICIPANT_B]`，不写 is_visible_to_all，不删除/覆盖其他成员，不改部门、组或黑名单。该接口线上立即生效，必须获得具体批准才可 PATCH；随后重新查询 A/B。[官方更新说明](https://open.feishu.cn/document/application-v6/admin/patch-5)

正式安装要在独立审核通过、真实适配完成和源码指纹再次核对后，以最终具体文件/版本与启动配置单独批准；当前不请求批准一个尚未闭合的发布件。批准安装也不等于批准消息正文或最终业务交付。

## 回退与剩余风险

安装前保留原程序指纹与备份；不备份业务库到公开包。未注册真实请求时可撤销新启动配置并恢复这 8 个程序文件。**一旦登记或发送过真实请求，不能简单卸掉隔离补丁**：先停专用执行准入，保留被动隔离与去重记录，待所有未知意图已对账、迟到消息处理方案获审后才移除。恢复旧程序直接放行历史消息不是安全回退。

账本缺失/损坏或关闭时抛错，阻止处理，不自动创建空账本回落业务路径。这样会暂停受影响采集或启动，属于正式影响，需纳入安装批准。不得通过停掉原事件消费者避开测试风险。

## 离线验证

32 个 Node 测试（17 顶层、15 子测试）通过；覆盖完整合成流程、拒绝、错人/应用/会话/码、无引用、过期、撤权、版本改变、无效时间、回读不一致、超时、重复/并发确认、未知外发、未知停止、账本丢失、迟到消息及普通消息继续处理。

6 个接线测试实例化本轮实际正式类副本：事件桥、私聊/@ reader、群发现、monitor、SQLite 最终写入及 core 输入/自动回执。原事件桥 5 项回归通过。local-http 接线仅语法检查，没有完整服务启动验收。合成 store 与正式库分离，未连接任何真实平台消息或模型。
