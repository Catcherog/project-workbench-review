# 公开副本与读回约定

公开材料只含本轮要求摘要、相关差异、新文件和关键上下文、合成测试证据、必要截图、UI接口及校验清单。未包含原始GOAL、私人聊天、实际测试项目正文、身份回包、账号配置、数据库、正式业务数据或内部文档原件。

审核副本把本机绝对路径替换为稳定的REVIEW_SOURCE、REVIEW_MAIN、REVIEW_HOME、REVIEW_TMP路径，并把个人称呼替换为“用户”。控制流、条件、断言与测试结果未简化。export-manifest列出原始文件指纹、公开指纹及是否发生脱敏；这份公开副本不是逐字等同的受测原件，源提交及原始指纹另行标明。

图片由隔离浏览器真实渲染取得；姓名、项目、材料均为合成。设置图仅截取对应设置区域，避免暴露本机路径。未对截图用生成模型重绘。

发布方从审核仓库固定提交读回每个文件并核对SHA-256后，另出实际回传。上传、执行端读回、GPT独立读取、GPT审计和用户验收是不同状态。
